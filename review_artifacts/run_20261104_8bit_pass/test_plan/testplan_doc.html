4.9 Divisor Latches

The divisor latches can be accessed by setting the 7th bit of LCR to ‘1’. You should
restore this bit to ‘0’ after setting the divisor latches in order to restore access to the other
registers that occupy the same addresses. The 2 bytes form one 16-bit register, which is
internally accessed as a single number. You should therefore set all 2 bytes of the register
to ensure normal operation. The register is set to the default value of 0 on reset, which
disables all serial I/O operations in order to ensure explicit setup of the register in the
software. The value set should be equal to (system clock speed) / (16 x desired baud rate).
The internal counter starts to work when the LSB of DL is written, so when setting the
divisor, write the MSB first and the LSB last.

This UART core is very similar in operation to the standard 16550 UART chip with the
