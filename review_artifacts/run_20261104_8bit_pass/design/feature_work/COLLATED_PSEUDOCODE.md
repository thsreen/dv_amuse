## Shared Setup

- SETUP_CLOCK_RESET: SELECT symbolic P_fixed per test; START continuous tone on wb_clk_i before reset HOLD fixed through traffic with no dynamic change or jitter; ASSERT reset via wb_rst_i then DEASSERT before any configuration with duration scaled to P_fixed; change period only between tests; BOUND waits by drain_cycles request_timeout_cycles TEST_TIMEOUT_CYCLES as TESTBENCH operational limits not DUT timing
- SETUP_BINDINGS_OWNERSHIP: BIND clock to wb_clk_i and reset to wb_rst_i with polarities symbolic; BIND wishbone_slave_interface to wb_adr_i wb_dat_i wb_dat_o wb_we_i wb_stb_i wb_cyc_i wb_ack_o wb_sel_i in 8_bit build pin values 0_to_6 normal 7 illegal; BIND uart_serial_data to srx_pad_i drive stx_pad_o observe; BIND modem_control_if to cts_pad_i dsr_pad_i ri_pad_i dcd_pad_i drive rts_pad_o dtr_pad_o observe; BIND interrupt_output passive to int_o observe; every DUT input owned or evidenced idle tie_off with no floating inputs; HOLD srx_pad_i idle and modem inputs stable when idle; LEAVE optional baud tick unbound until physical port documented
- SETUP_MONITORS: START wishbone monitor sampling on observed CLK edges reconstructing only completed ACK transactions flushing in_flight on wb_rst_i; START interrupt monitor sampling int_o edges with clock timestamp clearing pending on reset; START uart monitor realigning to next start_bit discarding partial on reset; TAP dedicated coverage subscribers to monitor analysis ports drivers never supply sampling events
- SETUP_BASE_PROGRAMMING: ENTER with Divisor 0 disabling IO LCR baseline IER 00h disabled FIFOs and shift registers cleared DLAB 0 bus idle_owned for handoff; PROGRAM symbolic divisor LSB MSB with DLAB gating MSB first at pin1 then LSB at pin0 under LCR DLAB1 then restore DLAB0 plus LCR line format FIFO trigger IER MCR Loopback via wishbone only; ENSURE DLAB 0 for normal IER IIR MSR access versus DLAB 1 for divisor alias at pin 0_to_1; configuration bus writes agree with uart driver and monitor symbolic data_bits parity stop_bits BIT_CYCLES
- SETUP_INFRASTRUCTURE_CLEANUP: per_agent sequences drive only own interface; stages execute in order with concurrent observation within stage; virtual sequences spawn_only with no VIFs or delays; CLEANUP to bus idle DLAB 0 Loopback 0 srx idle modem inactive for handoff; ABORT bring_up on operational timeout

## Stimulus Approach

- STAGE_CLOCK_RESET t_clk_seq t_chip_reset t_clk_cov: SELECT P_fixed START wb_clk_i before reset ASSERT wb_rst_i to active WAIT hold scaled to P_fixed DEASSERT to inactive WAIT stabilization HOLD P_fixed constant; CLEANUP hold stable to end
- STAGE_IDLE_XZ t_xz_check: AFTER reset deassertion with settle DRIVE idle known values via owners on wb_adr_i wb_dat_i wb_sel_i wb_we_i wb_stb_i wb_cyc_i plus srx_pad_i plus cts_pad_i dsr_pad_i ri_pad_i dcd_pad_i HOLD through checks; per_agent drives only own interface
- STAGE_RESET_STATE t_reset_state: DRIVE reset active then inactive with documented hold and deassert_to_access delay on observed edges; READ LCR at pin3 plus Divisor LSB MSB via DLAB gating plus IER IIR LSR via symbolic addresses; SAMPLE int_o and stx_pad_o idle on observed edges
- STAGE_INIT_CFG t_wb_init_cfg: WAIT chip_reset done; WRITE LCR DLAB1 at 3b011 then WRITE Divisor MSB first at 3b001 then WRITE Divisor LSB next at 3b000 then WRITE LCR DLAB0 then WRITE FCR trigger at 3b010 then WRITE IER enables at 3b001 with reserved 0; WAIT wb_ack_o after each LEAVE DLAB0
- STAGE_DIVISOR_SWEEP t_divisor_cov: WRITE LCR DLAB1; FOR zero 0x00_0x00 min 0x01_0x01 mid_low mid_high max 0xFF_0xFF plus cross 0x00_0xFF 0xFF_0x00 WRITE pin1 MSB then pin0 LSB MSB_first LSB_next WAIT ACK each; WRITE LCR DLAB0 LEAVE idle_owned
- STAGE_DLAB_GATE t_dlab_gate_chk t_addr_dlab_cov: WRITE LCR pin3 SYM_LCR_DLAB1 WAIT ACK; WRITE pin1 SYM_DIV_MSB then pin0 SYM_DIV_LSB WAIT ACK each; READ pin1 and pin0 with DLAB1 HOLD; WRITE LCR SYM_LCR_DLAB0 WAIT ACK; WRITE pin1 SYM_IER_PATTERN WAIT ACK READ pin1 DLAB0 HOLD; TOGGLE LCR DLAB1 READ divisor alias LCR DLAB0 READ normal alias; FOR each DLAB DRIVE pins 0_to_6 read and write where access permits plus pin7 read and write attempt to record disposition; CLEANUP to DLAB0 bus idle
- STAGE_REG_TOP t_wb_reg_cov t_wb_top_seq: WAIT init handoff DLAB0 idle; FOR each addr 0_to_6 DRIVE documented directions addr0 RBR_read THR_write addr1 IER RW addr2 IIR_read FCR_write addr3 LCR RW addr4 MCR_write addr5 LSR_read addr6 MSR_read DRIVE byte classes 0x00 0x01 mid_low mid_high 0xFF WAIT ACK; IF DLAB1 constrain 0 LSB 1 MSB RW; FOR N seeded randomize addr data_class direction within documented types update tracked DLAB on LCR bit7; CLEANUP DLAB0
- STAGE_UART t_uart_mon: BRINGUP via wishbone LCR DLAB1 MSB_to_1 LSB_to_0 LCR DLAB0 with symbolic nonzero divisor WAIT ACK; RX uart_serial_data drives srx_pad_i frames with symbolic data_bits parity stop_bits timed by BIT_CYCLES; TX passively observes stx_pad_o same timing emits TX without driving; on reset discard partial realign
- STAGE_TRAFFIC t_traffic_seq: SPAWN virtual normal_traffic_sequence spawn_only; normal directed FOR burst len WRITE THR payload DRIVE srx matching LCR DRIVE handshake WAIT ACK READ RBR observe stx int_o; loopback directed WRITE MCR Loopback1 WAIT idle FOR loop_bytes WRITE THR WAIT internal TX_to_RX READ RBR OBSERVE remapped modem OBSERVE int_o; random seed RANDOMIZE payload corner bias all_zeros all_ones within IER MCR plus gaps TX_RX interleave constrain internal versus external by Loopback; CLEANUP MCR Loopback0 DLAB0 bound by TEST_TIMEOUT_CYCLES
- STAGE_IER_IIR t_ier_iir_pend: INIT reset THEN READ IER at symbolic IER_ADDR plus READ IIR plus SAMPLE int_o; ENSURE DLAB0 before access; FOR enable 0x0 to 0xF with reserved 7_4 zero WRITE IER then READ IER back plus READ IIR plus SAMPLE int_o; IF traffic creates source WAIT IIR bit0 0 else VERIFY bit0 1; CLEANUP LEAVE DLAB0 idle WAIT drain
- STAGE_MODEM t_modem_irq: STAGE0 wishbone WRITES divisor line FIFO base with LCR DLAB0 MCR Loopback0 normal WAIT release; STAGE1 WRITE IER bit3 0 FOR each line cts dsr ri dcd DRIVE single toggle via modem agent THEN READ MSR at pin6 plus OBSERVE int_o; STAGE2 WRITE IER bit3 1 FOR each line DRIVE toggle THEN READ MSR and IIR plus OBSERVE int_o with concurrent wishbone modem interrupt observation; STAGE3 READ MSR to clear WAIT drain RESTORE Loopback0 DLAB0 bus idle
- STAGE_MODEM_TRAFFIC t_modem_traffic_cov: STAGE0 WRITE SYM_IER with modem enable 1 and READ back HOLD idle SAMPLE IIR baseline; STAGE1 TOGGLE one of CTS DSR RI DCD with no TX RX HOLD idle OBSERVE IIR plus READ MSR to clear; STAGE2 START TX via THR CONCURRENT with modem toggle OBSERVE during TX; STAGE3 DRIVE RX on srx CONCURRENT with modem toggle OBSERVE during RX; STAGE4 RUN TX plus RX CONCURRENT with modem toggle OBSERVE; STAGE5 RUN TX RX TX_RX with modem held inactive OBSERVE no_modem; REPEAT for each modem source; CLEANUP to inactive bus idle
- STAGE_E2E t_e2e_arch: WAIT reset deassertion THEN WAIT init_config with symbolic divisor LCR FIFO IER before enabling queues; WAIT normal_traffic burst with wishbone writes plus TX observe plus RX drive plus modem toggles under IER observe; WAIT loopback_traffic burst with internal TX to RX routing via symbolic loopback control; WAIT drain for flush THEN REPORT queues
- PASSIVE_STAGES t_wb_mon t_irq_baud_mon t_irq_id_cov t_clk_cov t_wb_scoreboard drive no DUT inputs SAMPLE edges completions timestamps forward to analysis ports; per_agent sequences drive only own interface virtual spawns only; stages execute in listed order generation order not permission for concurrent DUT traffic concurrent only where explicitly allowed

## Check Approach

- CHECK_XZ_IDLE t_xz_check via t_wb_mon t_uart_mon t_irq_baud_mon: SAMPLE every observed wb_clk_i edge wb_adr_i wb_dat_i wb_dat_o wb_we_i wb_stb_i wb_cyc_i wb_ack_o wb_sel_i wb_clk_i wb_rst_i plus int_o stx_pad_o srx_pad_i rts_pad_o dtr_pad_o cts_pad_i dsr_pad_i ri_pad_i dcd_pad_i; REPORT X_or_Z error; REQUIRE known non_XZ on wb_dat_o wb_ack_o and outputs after reset deassertion before reconstruction; infrastructure only not DUT oracle
- CHECK_KNOWN_RESET t_reset_state via t_wb_mon: RECONSTRUCT idle reads on observed edges then COMPARE LCR to 00000011b and Divisor to 0 and IER enables to disabled and LSR DR to 0 and IIR bit0 to 1 with int_o negated and no payload to confirm FIFOs and shift registers cleared; SAMPLE outputs known non_XZ else REPORT
- CHECK_INIT_READBACK t_wb_init_cfg: READ IER at pin 3b001 with DLAB 0 then COMPARE dat_o 3_0 to programmed IER_EN_SYM and dat_o 7_4 to 0000; no READ check on FCR address because write-only so trigger not observable by readback
- CHECK_DLAB_GATING t_dlab_gate_chk: ASSERT on each completed ACK at pin 0 and 1 that alias follows DLAB pin0_DLAB1 is DLL and DLAB0 is RBR_THR pin1_DLAB1 is DLM and DLAB0 is IER; COMPARE divisor reads with mask 0xFF when DLAB 1; COMPARE IER read at pin1 with mask 0x0F plus reserved 0xF0 equals 0 when DLAB 0; COMPARE toggle proof pin1_DLAB1 equals divisor not normal and pin1_DLAB0 equals normal not divisor; FLUSH in_flight on DLAB change
- CHECK_REQUEST_ROUTE t_traffic_seq t_e2e_arch via t_wb_scoreboard: SAMPLE completed STB_CYC to ACK into wb_req_queue and wb_ack_queue TRACK pending UNTIL ACK OR request_timeout_cycles then REPORT liveness; APPEND completed reads and writes retaining address we sel data ordering COMPARE against pending queue in order FLAG lost duplicated misordered; ON wb_rst_i FLUSH pending and RESET counters; every test observes at least one comparison with basic reset_known first
- CHECK_END_TO_END t_traffic_seq t_e2e_arch: SAMPLE THR writes excluding config into exp_queue and stx_pad_o TX into tx_queue and srx_pad_i RX into rx_queue and RBR reads into act_queue then COMPARE counts for loss duplication and ordered payload only if overrun free else REPORT overrun pending; COMPARE stx_pad_o equals 1 while MCR Loopback 1; COMPARE IER readback 3_0 versus programmed enables reserved 7_4 as 0; serial tx is DUT output rx is DUT input never self_compared; WAIT drain_cycles then REPORT queues and DISABLE queues
- CHECK_IER_IIR t_ier_iir_pend via top scoreboard: COMPARE IER readback low 4 to written enables 0x0 to 0xF and high 4 to 0; COMPARE reset IER 00h and IIR C1h with bit0 1 none; COMPARE IIR fixed mask bits7_6 11 and bits5_4 00 on every read; COMPARE IIR bit0 plus int_o level together with symbolic ASSERTED versus NEGATED levels FAIL on enable mismatch; COMPARE interrupt monitor queue versus wishbone IIR poll queue filtered by origin excluding config writes never compare event with itself
- CHECK_MODEM t_modem_irq t_modem_traffic_cov: COMPARE MSR delta DCTS DDSR TERI DDCD set after cts dsr ri dcd toggle and cleared after MSR read; COMPARE MSR status 7_4 complement in normal MCR Loopback 0 excluding loopback remap; COMPARE int_o negated when IER bit3 0 despite delta versus asserted when IER bit3 1 with IIR bit0 0 pending; COMPARE IIR 3_1 000 Modem Status with bit0 1 idle after clear respecting higher priority preemption; COMPARE toggle to MSR to int_o to IIR for loss duplication misorder; only qualify sampled IIR pending 0 when claiming modem_000 bin and 1 for idle plus fixed bits 7_6 11 and 5_4 00
- INAPPLICABLE_CHECK: t_clk_seq t_chip_reset t_clk_cov provide clock and reset stimulus only with no DUT output comparison; t_wb_mon t_irq_baud_mon provide passive sampling and timestamping only with no expected level; t_irq_id_cov t_wb_reg_cov and t_addr_dlab_cov provide coverage sampling only with no PASS FAIL including illegal pin 7 disposition without ACK or data COMPARE; no design_specific reference_model FSM is generated and no beyond simple RW RO WO mirrors modeled; every assertion receives property plus activation covers; inapplicability is structural not omitted checking

## Coverage Approach

- COV_CLOCK t_clk_seq t_clk_cov: SAMPLE observed wb_clk_i edges via passive monitor MEASURE P_sampled RECORD symbolic P_fixed plus P_sampled plus seed without inventing band boundary stratum; IF documented band map available THEN classify to band boundary low mid high ELSE retain raw; COVER one fixed_period context per test
- COV_WB_REG t_wb_mon t_wb_reg_cov t_wb_top_seq: SAMPLE cg_wb_reg_access on WB_ACK_O completion cp_wb_addr 0_to_6 plus illegal addr_7 and cp_wb_dir read WE0 write WE1 and cp_wb_data_class zero min mid_low mid_high max via dedicated subscriber tapping monitor analysis port; drivers never supply sampling events
- COV_DIVISOR t_wb_init_cfg t_divisor_cov: SAMPLE cg_dlab_divisor cp_dlab cp_div_lsb cp_div_msb on each divisor_byte write completion and SAMPLE rc_divisor_bytes lsb_zero mid max msb_zero mid max combined_zero_disables versus nonzero_enables with IGNORE DLAB_0
- COV_ADDR_DLAB t_dlab_gate_chk t_addr_dlab_cov: SAMPLE cg_cross_addr_dlab cross address with DLAB on each wb_ack_o on clock edge via dedicated subscriber; COMPARE pin wb_adr_i 0 1 2 3 4 5 6 plus 7 against LCR bit7 DLAB to bins addr0_dlab0_RBR_THR addr0_dlab1_DLL addr1_dlab0_IER addr1_dlab1_DLM addr2_to_6 normal variants plus illegal addr_7_any_dlab; per instance false single UART; exclude config payload semantics; TERMINATE on all bins hit or operational timeout
- COV_IRQ t_irq_baud_mon t_irq_id_cov t_ier_iir_pend: WAIT Wishbone read completion to address 2 then SAMPLE cp_iir_pending from bit0 and cp_iir_code from bits 3_1 for 011_RLS 010_RDA 110_Timeout 001_THRE 000_Modem with illegal 100_101_111 never and cp_iir_fixed bits7_6 11 bits5_4 00 plus IER enables 0000b to 1111b and reset IER 00h IIR C1h via dedicated subscriber; tick interval sampling is observation only without expected period until binding documented
- COV_TRAFFIC_MODEM_XZ t_xz_check t_uart_mon t_traffic_seq t_modem_traffic_cov: SAMPLE cover_xz_activation on each monitor sample plus cover_xz_error on each report plus cover_known_after_reset when known non_XZ; SAMPLE modem routing normal versus loopback via modem monitor RTS_PAD_O DTR_PAD_O CTS_PAD_I DSR_PAD_I RI_PAD_I DCD_PAD_I plus MCR Loopback; SAMPLE interrupt enables via IER 3_0; SAMPLE payload bytes corner bias all_zeros all_ones via wishbone plus uart TX versus RX taps; SAMPLE on CLK edges Modem Status IIR indication plus tx_active rx_active flags to bins modem_000_X_idle modem_000_X_tx_active modem_000_X_rx_active modem_000_X_tx_rx_active no_modem_X_traffic per instance false
- INAPPLICABLE_COVERAGE: t_chip_reset t_reset_state t_wb_scoreboard define bring_up and checking only with no bins; t_e2e_arch and t_modem_irq are observed via scoreboard tallies and COMPAREs with no dedicated bins and are covered by addr DLAB IER IIR and modem traffic crosses; clock period fixed per test boundary and seeded stratum deferred until bands defined; inapplicability is structural
