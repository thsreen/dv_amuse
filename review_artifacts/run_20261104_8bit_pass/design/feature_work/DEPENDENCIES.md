# Feature dependency plan

Dependency analysis orders fixed-period clock then chip reset then WISHBONE init config then top stimulus and normal-loopback traffic, with WISHBONE UART interrupt-baud monitors before DLAB interrupt LSR reset-state X-Z scoreboard checks and coverage, and top virtual spawning via shared sequencer config.

- **t_wb_init_cfg**: depends on t_chip_reset; independent of t_clk_cov, t_irq_baud_mon, t_irq_id_cov, t_reset_state, t_wb_mon, t_wb_reg_cov, t_wb_scoreboard, t_xz_check
- **t_chip_reset**: depends on t_clk_seq; independent of t_clk_cov, t_irq_baud_mon, t_irq_id_cov, t_wb_mon, t_wb_reg_cov, t_wb_scoreboard
- **t_traffic_seq**: depends on t_wb_init_cfg; independent of t_addr_dlab_cov, t_clk_cov, t_divisor_cov, t_dlab_gate_chk, t_ier_iir_pend, t_iir_prio_fixed, t_irq_baud_mon, t_irq_err_chk, t_irq_id_cov, t_line_err_cov, t_lsr_status, t_reset_state, t_uart_mon, t_wb_mon, t_wb_reg_cov, t_wb_scoreboard, t_wb_top_seq, t_xz_check
